# 个人资产页面

入口：Binance Dashboard 顶部 **个人资产**，路径 `/assets`。

## 总览布局与股票盈亏

总览顶部先展示总资产、已记录股票浮动盈亏、账户覆盖与每天两次更新计划；紧接资产类型饼图和平台分布，再展示 AI 点评、平台账户与折叠的数据来源详情。手机端按相同顺序排列。

`portfolio.stockPnl` 按账户保存带符号的股票及股票 ETF 未实现盈亏，记录原币、日期、来源和日期依据。每个账户最多一条汇总，不叠加个股盈亏。顶部按所选 CNY / USD / HKD 折算显示；盈亏已体现在当前市值中，不再次加入或扣减总资产。缺失值不按零处理，待确认账户排除，缺汇率项单列。可从总资产卡片的“更新盈亏”修改，隐私模式同时遮蔽金额、明细与编辑草稿。截图盈亏保留原来的日期依据，不因资产价格刷新而伪装成最新盈亏。

## 数据范围

支持汇丰基金、ZA Bank、富途、盈立、OKX、币安、A 股、民生银行、TokenPocket、Polymarket 和 Future，同平台可以添加多个命名账户。

- 手动记录账户总额或持仓估值。
- 上传 PNG/JPEG/WebP 截图，在浏览器内识别并逐项核对后保存。原图和 OCR 文本不上传或存入资产记录。
- 导入 UTF-8 CSV，下载空白模板，编辑预览并明确确认更新已有记录。
- 总资产卡片可切换 CNY / USD 显示；外币自动按最新可用汇率换算。USD、USDT、USDC 分别核算；缺汇率的记录显示待换算。
- 资产版图按已保存记录自动整理各平台的计价币种与原币金额，多币种分开列示；可从“纠正币种”逐条核对并保存，不会自动兑换金额或批量覆盖整个平台。
- 截图识别优先使用明确币种代码、中文名称和估值标记。仅有含糊的货币符号或多种冲突币种时保留待核对；已有记录及手动纠正的币种不会被再次识别覆盖。持仓币种与估值币种分别理解，例如 USDT 的 USD 市值仍以 USD 记录。
- 每个账户使用账户总额或持仓合计的一种统计口径；另一种保留但不累加。
- 按平台、资产类型、币种展示分布和集中度，并标记记录日期与缺失汇率。总览的“资产类型”卡片可点击进入持仓筛选，分析页也可按类型查看明细。
- 类型包括现金、定期存款、货币基金、股票、股票ETF、基金、债券、稳定币、加密资产、组合资产、其他和未分类。货币基金与现金、稳定币与银行存款、股票ETF与个股分别统计；未展开的组合保留为组合资产，不能据此推断底层敞口。
- 类型筛选保留待确认、缺汇率和口径排除的匹配记录，并明确标记；筛选合计只包含已核算记录。隐藏金额时同时隐藏类型金额、占比和含金额的备注。
- 总览与分析页以环形饼图展示资产类型，配套颜色图例、金额、占比和明细筛选；只包含已核算资产。空数据或零合计不绘制比例，隐藏金额时也移除饼图的比例图形。
- 未确定平台或可能重叠的账户保留为待确认，独立展示原币金额，不计入总额或分布。可编辑账户的平台、名称、备注和确认状态。
- 原币金额按选定口径分币种保留作为核对参考，人民币总额和分布自动换算；截图不含完整日期时注明导入日期，不能当成已核实的估值日期。
- 保存历史估值快照；快照变化不能直接当作投资收益。CSV/JSON 导出当前资产与历史摘要。

页面展示已入账资产，未录入的资产和负债不包含在内。可单独授权 OKX 和富途读取资产，Polymarket 和 Future 使用公开持仓地址；不执行交易。

## 自动汇率

总览直接显示折合人民币资产，汇率详情为只读表格，不再要求手动填写。页面后台轮询降为每 12 小时一次（有草稿、正在保存或页面隐藏时跳过）。账户资产、基金与 ETF 估值统一在北京时间每天 09:00、21:00 检查；页面打开与币种切换不会额外拉取账户资产。汇率仍按需获取最新可用报价，服务器缓存 5 分钟，也可点击“刷新汇率”。

总资产卡片右上角可切换 CNY / USD，并在当前设备记住选择。切换时刷新自动汇率；美元显示由人民币估值除以当前 USD/CNY 汇率计算，总额、当前分布图及持仓折算金额保持同一显示币种。缺少有效 USD 汇率时明确显示待换算，不默认 1:1。显示偏好不写入资产账本，原币金额不变；汇率详情仍以 CNY 说明每单位报价，历史快照保留当时冻结的 CNY 估值。

- 法币使用 [Coinbase 公开当前汇率](https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates)，统一从 USD 基准计算每单位外币折合 CNY。源不提供精确行情时间，因此展示获取时间，不能将其冒充报价发生时间。
- USDT 和 USDC 分别使用 [Kraken 最近成交](https://docs.kraken.com/api-reference/market-data/get-recent-trades)的独立美元价格，再按当前 USD/CNY 换算；不会固定当作 1 USD。
- 当前法币接口不可用时，使用 [Frankfurter / ECB 日参考](https://frankfurter.dev/)，保留具体日期和日参考标记。刷新失败沿用仍有效的缓存并明确显示延迟；稳定币原始成交超过 24 小时、法币缓存或日参考超过 7 天时排除，未知不当零。
- 自动汇率仅写入 `state/personal-assets-fx.json`（`0600`）。刷新不修改账户、原币金额、原始资产版本或历史快照；客户端提交的汇率不会覆盖原账本。JSON 导出附带当前自动汇率及来源以便复核。
- 新快照冻结当时自动汇率及来源。同一资产版本可以保留不同行情的快照；相同有效行情保持幂等。历史快照不按今天汇率重算。

这些汇率用于资产参考估值；自动刷新汇率并不代表截图持仓或银行余额已经更新。

## 只读账户同步

在 `/assets` 右上角点击“只读同步”。所有授权、状态和预览接口沿用 Dashboard 登录；提交同时校验请求来源。首次核对预览并入账后，独立的服务器定时器每天北京时间 09:00、21:00刷新。未授权时不连接交易账户，公共汇率仍会自动更新。

- **OKX**：在官方 API 管理创建独立密钥，仅勾选 **Read**，绑定服务器 IP **173.199.122.23**。在本站选择账户实体（全球站、美国/澳洲、EEA），填写 API Key、Secret Key、API Passphrase。程序先从官方账户配置验证权限，拒绝 Trade、Withdraw 或未知权限。三个资产 GET 接口采用固定域名和路径，不使用钱包私钥。
- **富途**：点击“前往富途授权”，在 `https://webapi.futunn.com/oauth2/authorize/confirm` 完成官方登录及 OAuth 2.1 + PKCE 授权。仅保留 `trade:read`（资产/持仓读取），拒绝 `trade:write`、`quote:write` 等写入范围。回调必须匹配发起登录会话、一次性 state 和十分钟有效期；授权返回后选择真实证券账户，读取预览再确认入账。无需 OpenD，也无需向本站提供富途密码。
- **Polymarket**：填写 Polygon 上实际持有仓位的公开地址，无需签名、私钥或助记词。读取 Data API v2 的全部分页仓位、组合仓位和官方估值，并读取同区块的 Polygon pUSD 现金；数据完整、新鲜且核对一致后才允许入账。充值地址与持仓地址可能不同，不能将充值地址余额当作整个平台资产。pUSD 与仓位按独立 USDC/USD 报价估值，不硬编码稳定币等于 1 USD。
- **Future.news**：Solana USDC 充值地址并非预测仓位地址。先在官方页面核对充值地址与所选交易账户的对应关系，再绑定该 Polygon 交易账户。复用其 Polymarket 上游的全部分页仓位、pUSD 链上现金和完整性核对，不筛选 BTC 系列；未到账充值不包含在内。相同交易地址不能在 Future 与 Polymarket 重复计入；断开后保留入账来源去重记录。
- **OKX Web3 / TokenPocket**：使用用户明确指定的公开地址与网络。完整代币索引需要独立的 [OnchainOS Developer API 凭据](https://web3.okx.com/onchainos/dev-portal)，与交易所 Read Key 不同；只在安全表单填写 Key、Secret、Passphrase。本站白名单仅查询资产，不保存外部钱包私钥、助记词或签名材料，也不复制本机 Agentic 登录会话。未核实提供商存在强制只读 scope，因此不把本站只查询描述成密钥自身权限保证。
- 钱包同步范围为已指定链上的原生币、ERC20、SPL / Token2022 代币。已识别的真实数量保留；缺价、报价过期或尚未独立核验的代币列为“未估值”，不使用 0 占位。总额与分布只纳入已定价部分，并在总览、预览和账户处明确“部分估值”。NFT 与未核实协议不包含在该代币市值中；聚合器 DeFi 值未与账户和链上结果核对前不能加总。JSON 带来源与未估值清单，CSV 仅含已入账金额。
- 首次入账先保存原版本快照，并在下拉框中明确选择要更新的已有账户；没有该平台账户时才能新建对应目标，避免同一笔资产在旧手动账户和新同步账户重复计入。入账后绑定目标，不能静默改绑为另一个本地账户；OKX Web3 不可作为交易所同步目标。平台净资产总额只计一次。OKX 明细必须完整且精确对齐总额后才用于类别统计；否则以账户净资产统计、明细仅供核对。富途使用返回币种的 `total_assets`，不加上购买力、现金或证券小计。
- 上游读取或校验失败不覆盖资产，显示失败或更新延迟。总览显示完成首次同步的账户覆盖率；账户与持仓显示源资产时点、最近成功读取、最近成功入账、最近尝试与下次检查。源不提供资产时点时明确写出，不把抓取时间当作资产时点。源币种金额、独立美元报价及其时点、最后入账覆盖说明和碎仓口径一并保留，隐藏金额时也隐藏这些敏感数值。同步配置不可读时，单独显示同步状态未知，仍展示有效资产账本。定时同步在提交前再次校验目标账户和版本；手动修改此账户会暂停自动覆盖，需要重新核对预览。汇率自动独立获取，不把稳定币数量当美元金额。
- “断开本站同步”删除服务器保存的该平台凭证并停止刷新，保留已入账资产、未估值数量、来源说明和历史。彻底撤销访问，还需到 OKX 删除 API 或富途官方控制台撤销 OAuth 授权。

凭证和公开地址绑定仅写入 `state/personal-assets-sync.json`，权限 `0600`，不进入资产导出、状态响应或日志。自动更新另留每个平台一份滚动私有备份 `state/personal-assets-sync-<provider>-previous.json`，避免每天北京时间 09:00、21:00耗尽不可变快照数量。备份这些文件时须按凭证文件保护。未授权前保留现有截图数据，不宣称账户已连接或已完成真实同步。

官方接口依据：[OKX API](https://www.okx.com/docs-v5/en/)、[富途 OAuth 入门](https://open.futunn.com/api/overview/getting-started)、[富途资产接口](https://open.futunn.com/zh-cn/api/trading/account/get-funds)。富途授权文档的查询参数表未列出 scope；本站显式请求只读，并以最终令牌返回范围严格校验，含写入权限即拒绝。

## 存储与访问

页面、脚本、OCR 模型和 JSON API 都位于 Dashboard 的同一登录保护内。
本地开发沿用现有的 loopback-only 模式；公网访问需使用项目已有的 HTTPS 与 Dashboard 登录。

默认资产文件：

```text
state/personal-assets.json
state/personal-assets-snapshots/<uuid>.json
state/personal-assets-imports/<batch>.json
```

`PERSONAL_ASSETS_DIR` 可用于指定独立资产目录（例如隔离测试目录）。新建资产文件权限为 `0600`，新建专用目录为 `0700`；既有共享 state 目录权限不变。

生产交易授权对整个 `src/*.mjs` 集合校验身份。生产资产模块、共享导航及 OCR 必须放在 `/opt/binance-agentic-personal-assets/releases/<id>/`，由仅在 Dashboard 启用的 `ops/personal-assets/dashboard-loader.mjs` 定向加载。不能将新增模块写入生产交易 `src/`。版本目录及代码由 root 拥有且不可被组或其他用户写入；入口加载器校验十六个代码哈希。

Dashboard systemd 配置使用 `deploy/binance-agentic-dashboard.assets.conf`，保留 BTC 与授权加载器。更新 Dashboard 入口时，需备份并同步现有授权 release 中的 `dashboardSourceHash`，保持源码校验开启；不能更改 `liveCodeHash`、授权策略或续签停止状态。

资产保存采用临时文件、同步落盘、原子替换和跨进程写锁，并检查版本号防止旧页面覆盖新数据。重复保存同一资产版本及有效行情会返回同一份快照。主资产文件只保存快照摘要；完整快照放在独立文件，避免随着历史增长反复加载全部资产。派生汇率缓存采用原子替换，避免进程意外退出后残留锁阻止后续获取。

原有 `config.json`、交易状态、钱包会话、审批和风控文件不参与此资产页的读写。备份资产时，应同时备份上述资产路径；导出文件包含真实金额，不受页面隐藏金额开关影响。

聊天中明确要求解析入库的截图可直接整理入账；原始截图不另行复制到项目，私有导入清单记录来源文件 SHA-256、解析数据、核对规则与未确定事项。未知归属不推断成已确认账户。旧手工汇率保留在历史账本中，不再作为当前自动估值数据。

## OCR 资源

`assets/personal-assets/ocr/` 固定使用 Tesseract.js 7.0.0、Tesseract.js-core 7.0.0 和 eng/chi_sim/chi_tra 识别模型。包含随附许可证和来源说明。仅使用 LSTM 引擎，资源全部由本 Dashboard 提供，首次识别需要下载模型到浏览器。
