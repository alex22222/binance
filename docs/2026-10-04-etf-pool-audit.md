# ETF 池与调仓频率：修正回测及执行门禁

## 结论

**P0 核算完成；研究结果可发布，但实盘晋级仍为 WITHHOLD。**

修正后，QQQ/SPY＋SGOV 周频池在本次全部 4 个历史区间 × 5 个成本场景中，年化回报和最大回撤均优于原四只风险 ETF 池。但它仍是已见历史上的相对改善，不是策略已经盈利有效、实盘有资格或未来会少亏的证明。

月频值得独立研究；“越慢、回看越长就越好”不成立。126 日组在多个时期弱于 63 日组；2022 年多个长回看组也弱于周频组。保留全部失败结果，不把 252 日组改称优胜策略。

本次没有修改交易运行模块、生产配置、标的池、持仓、授权或旧 Paper 账本，没有提交测试订单。

## 一、原分析复核

找到原始 `bt.py`、`runall.py` 和 Yahoo JSON；原文件未修改，未读取 pickle。现有 09-18 基础轮动在当时的原始数据上精确重现 CAGR、最大回撤、Sharpe 和换仓数。这验证的是旧 RSI 排名引擎，不是完整的 Live 防守与执行系统。

使用原 Python 函数、2007-07-02 至 2026-09-30、0.35% 往返假设，可重现原帖周频结果的量级：

| 原脚本周频池 | 年化 | 最大回撤 |
| --- | ---: | ---: |
| 四只风险 ETF | 1.62% | 46.43% |
| QQQ/SPY | 3.44% | 41.60% |
| SPY | 3.13% | 32.62% |

原脚本的 **0.35% 成本没有翻倍**：单边 0.175%，一卖一买复合损耗约 0.3497%。但发现以下缺陷：

1. **止损日期错位**：当日收盘触发后，立即读取次日开盘价，并把卖出净值记入当日。这会污染日收益、回撤及 Sharpe。原 `blocked_period` 变量未被消费，跨周重入也可能偏离实盘。
2. **首日成本被指标归一化消掉**：CAGR 用末值除首日收盘净值，而不是初始资本；回撤峰值也遗漏初始资本。
3. **虚构暖机**：BIL 之前补了固定 4.5% 年收益。默认 2007-07 的 20 日版本已有足够真实 BIL 数据，不受该合成暖机直接影响；长回看版本可能受影响。
4. **防守资产止损缺失**：原脚本排除 SGOV，Live 没有此排除。
5. **对照 SMA 暖机不足**：`runall.py` 先取 VTI 与短债共同历史再算十月均线，丢失 VTI 早期已存在的数据；该 SMA 组未纳入本次修正矩阵，不据此做策略排名。

## 二、冻结后的修正规格

- 数据冻结截止 2026-09-30。保存原始 JSON、原脚本、哈希、恢复时间、源文件 mtime；**原始采集时间未被验证**，mtime 不冒充采集时间。
- BIL 仅在 SGOV 有真实历史之前作为代理。拼接通过重叠日缩放保留 BIL 收益率；不补造上市前数据。
- 全样本组各规则共同从 **2008-06-02** 开始，确保 252 日真实暖机；2020 年起、2022 年、2023 年起各分期组使用各自统一窗口。不能将新表与原帖 2007-07 开始的数字当作完全同区间结果。
- 风险资产动量须为正、RSI(14)≥40，取动量最高者；无风险候选时仅防守动量为正才持有 SGOV，否则现金。防守动量与各研究变体的风险回看同窗。
- 周频 20 日与月频 63/126/252 日全部保留。上一完整交易日信号，周期首个观察到的交易日开盘代理成交。
- 收盘估算含成本卖出净值触发 -8% 后，**下一观察交易日开盘**才成交；成交所在决策周期不再新买。月频禁入整月是本次登记的研究假设，不是当前 Live 原规则。
- 五档成本：0%、0.35%、0.45%、1% 全包往返百分比，以及 **0.15% 报价损耗往返＋每边固定 0.05 USD Gas**。固定 Gas 档不再叠加所谓全包费，避免重复扣费。
- 主矩阵初始 50 USD、利润全部复投；另做最多 50 USD 单笔、利润留现金的诊断。两者不是同一资金管理规则。
- CAGR 从初始资本计算；峰值包含初始资本；Sharpe 使用零无风险利率口径。最后持仓按收盘估值，**不强制末日平仓**；基准同口径。
- 基准目前只按 **0.35% 往返**计算，不能把它当所有成本档位的匹配基准。

## 三、修正后的主表

共同窗口 2008-06-02—2026-09-30，0.35% 全包往返，数字为 **年化 / 最大回撤**。所有数值是底层 ETF 日线代理，不是链上成交结果。

| 规则 | 原四只＋SGOV | QQQ/SPY＋SGOV | SPY＋SGOV |
| --- | ---: | ---: | ---: |
| 周频 20 日 | 1.80% / 41.34% | 3.74% / 36.46% | 4.30% / 26.46% |
| 月频 63 日 | 8.51% / 27.81% | 9.74% / 27.33% | 7.84% / 19.99% |
| 月频 126 日 | 7.06% / 31.27% | 8.92% / 31.64% | 5.59% / 27.96% |
| 月频 252 日 | 8.13% / 33.73% | 11.05% / 22.80% | 7.65% / 21.80% |

同窗买入持有：SPY 11.72% / 50.70%；QQQ 16.80% / 49.37%；BIL/SGOV 拼接防守代理 1.32% / 0.78%。

周频缩池的分期对照（0.35%）：

| 时段 | 原池年化 / 回撤 | 缩池年化 / 回撤 |
| --- | ---: | ---: |
| 共同长窗口 | 1.80% / 41.34% | 3.74% / 36.46% |
| 2020-07 起 | 3.15% / 34.77% | 7.95% / 26.71% |
| 2022 年 | -19.11% / 29.20% | -11.02% / 18.41% |
| 2023 年起 | 10.88% / 14.35% | 16.32% / 11.47% |

这些区间是预先固定的历史分段，**不是没有看过的独立样本外**；各区间重新以 50 USD 开始，年化口径也不是逐年的实际收益简单平均。

在 1% 往返压力下，长窗口原池年化 -9.15%、缩池 -6.32%，说明缩池不能解决执行成本过高的问题。固定 Gas＋50 USD 单笔上限诊断中，长窗口原池年化 1.27%、缩池 2.91%，不能用不受单笔限额约束的复投 CAGR 代替这一诊断。

## 四、账本验收与证据边界

共 240 个矩阵结果＋12 个基准＋12 个单笔上限诊断，全部保留。逐笔记录成交日期、信号日期、价格、数量、预算、百分比费用、固定 Gas 和交易后现金；逐日记录现金、持仓、估值。

独立只读 checker 直接从冻结 JSON 重建行情，复核 **24,402 笔交易、486,552 个日净值、587 次止损**，通过。检查覆盖实际行情匹配、数量×价格与预算/费用、现金余额、持仓数量、最大回撤及止损次日成交。其建议的永久对账断言和跨周期禁入测试已补入代码。

仍不具备：完整历史交易日缺失检查、分钟级可执行报价、RFQ 拒单、审批延迟、实盘全部成本与风险门槛、真实前向收益证据。日线代理止损不能保证实盘退出价；已观察历史也存在标的挑选偏差。因此 `automaticTradingEligible=false`、`livePromotion=WITHHOLD`。
