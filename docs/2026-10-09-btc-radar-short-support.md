## 目标、范围与验证循环

本次为一次性修复：先读取现有实现和生产只读证据，补充失败测试，再修改采集、方向计算与页面，最后通过测试和真实只读响应验证。验收是三类 BTC-USDT 永续持仓能够独立展示，多空风险方向正确；不下单、不改变策略、风控、钱包或授权。进度和上线边界记录在本文件。

## 根因与真实证据

- 原接口只读取合约马丁格尔，并过滤 `direction=long`，普通永续与合约网格完全未接入。
- 用户截图实际是 BTCUSDT 永续 **合约网格做空，10x**，不是合约马丁格尔。

- 当次读取网格平均价约 82633.64、强平价约 99006.8。价格与盈亏随时间变化，此处不是实时报价、历史成交确认或投资建议。

## 修复内容

1. 马丁格尔：接入多头和空头，收集所有运行中的 BTC 机器人，保留原来指定 ID / 最新机器人作为默认选中的行为。
2. 普通永续：通过 `/api/v5/account/positions` 区分显式 `long/short` 和 `net` 正负张数；张数按合约元数据换算成 BTC，不把负张数变成负显示仓位。
3. 合约网格：通过 `/api/v5/tradingBot/grid/orders-algo-pending` 和 `/grid/positions` 读取自身持仓，区分策略总收益、网格收益和当前仓位浮动盈亏；不与普通账户或 DCA 合并均价、汇总收益。
4. 页面：多笔持仓分别展示并可切换详情；明确做多/做空、BTC 数量、收益类型和旧数据标记。空头危险区在止损以上，止损预览限制在现价以上，止盈在现价以下。
5. 风险：空头上涨亏损、下跌盈利；DCA 空头补仓阶梯递增，只有先于止损成交的挂单计入场景。空头止损使用上涨触价盘、止盈使用下跌触价盘。未知止损/止盈/强平不显示为 0 或安全距离。
6. 数据边界：三类持仓来源分别采集和回退旧数据；首轮失败显示采集失败，而非无仓或伪造旧值。旧数据不用于发送持仓变化提醒；提醒按持仓 ID 比较，避免换机器人被误判为加仓。

网格与普通永续不套用 DCA 补仓模型：只对固定当前仓位作退出损益测算，强平价直接读取 OKX。网格未来成交、其他挂单、滑点和未来资金费未计入，结果不是最大亏损。普通永续仅识别唯一的全仓平仓附带价格委托；分批、移动、指数价止损或其他机器人不宣称已覆盖。比例止损不强行换算固定价格。

综合评分保留原来的“BTC 下跌压力”口径，不能把高分解读为空头高风险，也不把 200 日均线回避状态变成做空指令。现有已设置价格的多头样例仍与原 Python 输出逐字节相同。
