# 双钱包交易总览

日期：2026-11-11，北京时间。本篇保留本地实现验收记录；后续全仓审查、提交和隔离发布状态见 [发布记录](2026-11-11-uncommitted-review-release.md)。

## 用户确认的范围

- 重构 `/dashboard`，在 Binance Agentic Wallet 与 OKX Agentic Wallet 之间切换。
- 各自展示资产、数据日期、运行来源和策略选择。
- 用户明确选择“保存待启用策略，不立即交易”。方案保存不等于运行策略变更。
- 不登录或迁移钱包，不搬运密钥，不执行订单，不修改风控、授权或自动续签。

### 资产边界

`GET /api/agentic-wallets` 仅读取既有资产账本、同步状态及脱敏 OKX 运行快照。不调用同步 preview/apply，不创建钱包会话。

资产仅匹配平台 `币安Agentic Wallet` / `OKX Agentic Wallet`。OKX 交易所、OKX Web3、其他钱包不混入。账户汇总与持仓明细按原账户口径展示，不再次相加，不将不同币种或不同钱包的数字合成总额。

账本日期不升级成实时资产时点，`lastFetchedAt` 或快照搬运时间不替代原入账和采样时间。只有已入账、精确绑定到对应账户的未估值记录才展示；新 preview 不进入资产列表。缺价资产展示原始数量字符串，不以 0 USD 占位。

Binance 的运行摘要沿用 `/api/snapshot` 原有只读查询；该旧接口可能读取钱包可用 USDT 和行情，不是完全无网络的文件读取。新页面每分钟重新读取，不修改原 Bot 调度。

OKX 来源“回调二波”与资产账本之间没有账户身份绑定证明，因此明确标成独立策略来源，不声称就是所选资产账户正在运行的策略。页面接入不代表 OKX 源采集已启动，也不保证来源新鲜。

### 策略草稿

- `GET /api/agentic-wallets/preferences`：读取偏好。
- `POST /api/agentic-wallets/preferences`：只允许 `walletId`、`strategyId`、`revision`。
- 文件：`PERSONAL_ASSETS_DIR/agentic-wallet-preferences.json`，权限 `0600`，按钱包分别保存。
- 保留现有 Dashboard 鉴权；写入要求有效 Origin 和 JSON。策略必须属于对应钱包选项。
- 独立排他锁、版本冲突 `409`、临时文件原子替换；不覆盖损坏或符号链接文件。
- 手机和电脑共用服务器端草稿；页面切换本身没有 POST。
- `observe-only` 是拟选方案，不会停止当前策略。
- Binance 选项复用既有策略目录，标明研究 / Shadow / 执行支持；OKX 只列已有独立回调二波来源和仅观察选项，不伪造可执行的币安策略适配。
- 执行路径没有消费者读取该文件，不写 `strategy-control.json`、持仓、审批、授权或风控配置。

## 发布隔离

新增三个 UI 模块：

- `src/agentic-wallet-overview.mjs`：资产展示投影、策略选项、独立草稿存储。
- `src/agentic-wallet-html.mjs`：布局与 nonce 保护页面。
- `src/agentic-wallet-client.mjs`：钱包切换、展示、草稿保存。

三者加入现有 Dashboard 独立发布 loader / hooks / staging 精确白名单。共享交易策略目录仍从原 Bot checkout 读取，不复制或更改交易模块。原执行页面由既有路由继续渲染，原审批、登录与实盘闸门没有被新页面绕过。

工作区存在大量并行改动，本次没有全量暂存、提交或发布。后续如要求部署，必须另行核对生产身份，采用 UI 隔离发布；不得直接将本地 `src` 覆盖生产交易目录。
